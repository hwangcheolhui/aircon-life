### 1.2 핵심 기능 상세

#### F-CUS-QUO-04 자동 표준 견적 산출
| 항목 | 내용 |
|---|---|
| 입력 | 법정동 코드, 기기 목록[{device_type, clean_level, 수량}], 옵션, (선택) 희망 일시 |
| 처리 | ① `service_area`로 거점·서비스 가능 여부 판단 → ② `service_product` 매칭 → ③ 거점·기간·고객유형에 맞는 `price_policy` 선택(우선순위 높은 것) → ④ 대수 할인 계산 → ⑤ `surcharge_rule(AUTO_QUOTE)` 중 권역외 출장비 적용(희망 일시가 있으면 야간·휴일도 적용) → ⑥ 예상 소요시간 = Σ(base_duration × 수량) → ⑦ `quote`·`quote_item` 저장, 단가·규칙 스냅샷 보관 |
| 출력 | 항목별 금액, 할인, 할증, 총액, 예상 소요시간, 포함/불포함 항목, "현장 추가요금이 생길 수 있는 경우" 목록(ON_SITE 규칙), 유효기한 |
| 규칙 | BR-010~015 |
| 예외 | 비서비스 지역 → 견적 불가 안내 + 오픈 알림 신청 / 시스템·천장형 4대 이상 → "현장 확인 견적" 안내(B2B 문의 유도) |

#### F-CUS-RSV-01 일정 선택
| 항목 | 내용 |
|---|---|
| 입력 | 거점 ID, 예상 소요시간, 필요 인원 |
| 처리 | `time_slot`에서 slot_kind=NORMAL, 잔여(capacity−booked) ≥ 필요 슬롯 수인 시간대 조회. 소요시간이 2시간 이상이면 연속 슬롯 확보 필요 |
| 출력 | 날짜별 가용/마감, 시간대 버튼, 할증 대상 시간대 배지 |
| 규칙 | BR-011(야간), BR-012(휴일), BR-021(슬롯 동시성) |
| 예외 | 선택 후 결제 중 슬롯 마감 → "다른 시간을 선택해 주세요" + 재조회 |

#### F-CUS-ORD-04 추가요금 동의
| 항목 | 내용 |
|---|---|
| 트리거 | 기사가 F-TEC-WRK-05에서 추가요금 등록 |

#### F-ADM-STL-02 정산 계산
| 항목 | 내용 |
|---|---|
| 대상 | 기간 내 `work_order.status=DONE` AND 주문 `COMPLETED` AND `is_settlement_target=true` AND 미정산 |
| 계산 | 건별: 기사 배분 = 작업비 × 배분율(등급·계약형태별 정책) / 2인 작업 = 주기사(100−지원율)% · 지원기사 지원율% / 추가요금 = 추가요금 × 추가요금 배분율 / 동행(ACCOMPANY) 배분 0(교육비 별도 정책) |
| 합계 | gross → base_pay + extra_pay + incentive − deduction(자재 청구분·장비 대여) − cash_collected(현장 현금 수금 상계) → 과세대상 × 원천징수율(3.3%, FREELANCER) → net_pay |

## 7. 비기능 요구사항

| 분류 | 요구사항 |
|---|---|
| 성능 | 견적 산출 1초 이내, 목록 조회 2초 이내(1만 건 기준), 사진 업로드는 백그라운드·재시도 |
| 가용성 | 성수기(5~8월) 피크 대비 오토스케일링, 기사 앱 오프라인 임시저장 |
| 보안 | HTTPS, 비밀번호는 인증 서비스(Supabase Auth)에 위임, 개인정보 컬럼 암호화, 관리자 로그인 실패 잠금(5회째 실패 시 잠금, 기준 횟수 `system_setting.ADMIN_LOGIN_MAX_FAIL`), 관리자 비밀번호 최소 길이(`ADMIN_PASSWORD_MIN_LENGTH`)·영문+숫자, 관리자 접속 IP 제한(옵션, 환경변수 `ADMIN_ALLOWED_IPS`), 모든 테이블 RLS. **구현 기간 임시 개발 모드**: 환경변수 `ADMIN_AUTH_BYPASS=true`면 로그인 없이 관리자 화면을 읽기 전용(구현된 화면 READ만)으로 열람하고 상단에 "임시 개발 모드"를 표시. 등록·수정·삭제·다운로드·개인정보 원문 열람·비밀번호 변경은 계속 로그인 필요. `DATABASE_URL`·인증 환경변수가 아직 없으면 "DB 미연결" 안내와 함께 빈 목록(코드 표시명·기준값은 시드)으로 화면만 연다. 운영 전 반드시 끈다 |
| 권한 | RBAC(메뉴×행위) + 데이터 범위(전체/거점/본인). 화면 노출과 별개로 모든 데이터 변경은 서버에서 권한을 다시 확인 |
| 감사 | 개인정보 열람·다운로드·권한 변경·정산 확정 로그 |
| 사용성 | 고객 앱: 견적까지 3화면 이내, 큰 글씨·일러스트 기기 선택 / 기사 앱: 장갑 착용 고려 큰 버튼, 한 손 조작 / 관리자: 키보드 중심(엔터 조회, 탭 이동) |
| 호환성 | 고객 iOS 15+/Android 9+, 모바일웹 / 관리자 Chrome·Edge 최신 |
| 확장성 | 카테고리·기기유형·상품을 코드로 관리해 가전(세탁기·건조기·후드·매트리스) 확장 시 스키마 변경 없이 추가 |
