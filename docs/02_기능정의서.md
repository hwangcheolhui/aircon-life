### 1.2 핵심 기능 상세

#### F-CUS-QUO-04 자동 표준 견적 산출
| 항목 | 내용 |
|---|---|
| 입력 | 법정동 코드, 기기 목록[{device_type, clean_level, 수량}], 옵션, (선택) 희망 일시 |
| 처리 | ① `service_area`로 거점·서비스 가능 여부 판단 → ② `service_product` 매칭 → ③ 거점·기간·고객유형에 맞는 `price_policy` 선택(우선순위 높은 것) → ④ 대수 할인 계산 → ⑤ `surcharge_rule(AUTO_QUOTE)` 중 권역외 출장비 적용(희망 일시가 있으면 야간·휴일도 적용) → ⑥ 예상 소요시간 = Σ(base_duration × 수량) → ⑦ `quote`·`quote_item` 저장, 단가·규칙 스냅샷 보관 |
| 출력 | 항목별 금액, 할인, 할증, 총액, 예상 소요시간, 포함/불포함 항목, "현장 추가요금이 생길 수 있는 경우" 목록(ON_SITE 규칙), 유효기한 |
| 규칙 | BR-010~015 |
| 예외 | 비서비스 지역 → 견적 불가 안내 + 오픈 알림 신청(F-CUS-QUO-08) / 시스템·천장형 4대 이상 → "현장 확인 견적" 안내(B2B 문의 유도) |
| 계산 세부(단계 1 확정) | 공용 모듈 `packages/domain` `calculateQuote` 하나만 쓴다(고객·상담 콘솔·시뮬레이터 동일). ② 같은 (기기 형태, 작업 범위) 상품이 여럿이면 상품 코드 순 첫 번째 ④ **대수 할인**: 견적 전체 대수로 구간을 정하고, 상품마다 그 상품 가격 정책의 할인율을 상품 금액(옵션 제외)에 적용, 원 미만 버림, 상품별 `DISCOUNT` 행 ⑤ **권역 외 출장비**: `OUTER_AREA` 규칙이 사용 중이고 관할 지역 `service_area.travel_fee` > 0이면 그 금액 1건 / **야간**(`NIGHT`): 방문 시각 ≥ `condition_json.after`, `weekday:true`면 월~금·공휴일 제외 / **휴일**(`HOLIDAY`): `weekend:true`면 토·일, `holiday:true`면 holiday 테이블 날짜 / 둘 다 해당하면 금액이 높은 1건(같으면 휴일, BR-013) / 정액은 `per_unit`이면 ×전체 대수, 정률은 (상품 합계 − 할인) × %, 원 미만 버림 / 단가 기준일 = 희망 방문일(없으면 견적일, 한국 날짜). 고객 앱 견적은 방문 일시를 받기 전이라 야간·휴일 할증 없이 산출하고 예약(단계 2)에서 붙는다. 현장 확인 견적 기준 대수는 `system_setting.QUOTE_SITE_SURVEY_MIN_UNITS` |

#### F-CUS-QUO-08 서비스 지역 오픈 알림 신청 (단계 1 보강)
| 항목 | 내용 |
|---|---|

| 보안 | HTTPS, 비밀번호는 인증 서비스(Supabase Auth)에 위임, 개인정보 컬럼 암호화, 관리자 로그인 실패 잠금(5회째 실패 시 잠금, 기준 횟수 `system_setting.ADMIN_LOGIN_MAX_FAIL`), 관리자 비밀번호 최소 길이(`ADMIN_PASSWORD_MIN_LENGTH`)·영문+숫자, 관리자 접속 IP 제한(옵션, 환경변수 `ADMIN_ALLOWED_IPS`), 모든 테이블 RLS. **구현 기간 임시 개발 모드**: 환경변수 `ADMIN_AUTH_BYPASS=true`면 로그인 없이 관리자 화면을 읽기 전용(구현된 화면 READ만)으로 열람하고 상단에 "임시 개발 모드"를 표시. 등록·수정·삭제·다운로드·개인정보 원문 열람·비밀번호 변경은 계속 로그인 필요. `DATABASE_URL`·인증 환경변수가 아직 없으면 "DB 미연결" 안내와 함께 빈 목록(코드 표시명·기준값은 시드)으로 화면만 연다. 운영 전 반드시 끈다. **휴대폰 본인인증 임시 테스트 모드**: 본인인증 키 발급 전에는 `IDENTITY_DRIVER=mock` + `IDENTITY_MOCK_AUTO_VERIFY=true`면 휴대폰 인증 화면(C-AUTH-030, 기사 T-AUTH도 같은 규칙)에서 이름·번호 입력 후 [인증번호 받기]만 눌러도 인증 완료로 처리하고 화면에 "테스트 모드"를 표시한다. `IDENTITY_DRIVER=portone`이면 무시한다. 운영 전 반드시 끈다 |
| 권한 | RBAC(메뉴×행위) + 데이터 범위(전체/거점/본인). 화면 노출과 별개로 모든 데이터 변경은 서버에서 권한을 다시 확인 |
| 감사 | 개인정보 열람·다운로드·권한 변경·정산 확정 로그 |
| 사용성 | 고객 앱: 견적까지 3화면 이내, 큰 글씨·일러스트 기기 선택 / 기사 앱: 장갑 착용 고려 큰 버튼, 한 손 조작 / 관리자: 키보드 중심(엔터 조회, 탭 이동) |
| 호환성 | 고객 iOS 15+/Android 9+, 모바일웹 / 관리자 Chrome·Edge 최신 |
| 확장성 | 카테고리·기기유형·상품을 코드로 관리해 가전(세탁기·건조기·후드·매트리스) 확장 시 스키마 변경 없이 추가 |
